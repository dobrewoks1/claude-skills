# claude-skills

Скиллы для [Claude Code](https://github.com/anthropics/claude-code), которыми я пользуюсь в работе.
Пока здесь один скилл — `rating-index-ru`.

## Что такое скилл Claude Code

Скилл — это папка с файлом `SKILL.md`: в YAML-заголовке имя и описание («когда меня применять»),
ниже — инструкции для агента. Рядом могут лежать справочники, скрипты и шаблоны. Claude Code
видит описания всех установленных скиллов и подгружает нужный, когда запрос пользователя
совпадает с описанием. Справочники агент читает по мере надобности, поэтому большой скилл
не съедает контекст заранее.

Проще говоря, скилл — это упакованный опыт: порядок работы, грабли и проверки, которые иначе
приходится каждый раз объяснять заново.

## Установка

Скопируйте папку скилла в `~/.claude/skills/` (на Windows — `%USERPROFILE%\.claude\skills\`)
и перезапустите Claude Code.

```bash
git clone https://github.com/dobrewoks1/claude-skills.git
mkdir -p ~/.claude/skills
cp -r claude-skills/rating-index-ru ~/.claude/skills/
```

```powershell
git clone https://github.com/dobrewoks1/claude-skills.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse claude-skills\rating-index-ru "$HOME\.claude\skills\"
```

Чтобы скилл работал только в одном проекте, положите папку в `.claude/skills/` внутри проекта.
Проверка: в новой сессии попросите, например, «сделай рейтинг доступности автосервисов
Новосибирска — с чего начнём?». Агент должен начать с фазы 0 и правил замера.

## rating-index-ru — индекс цифровой доступности локального бизнеса

Скилл ведёт агента по конвейеру «ниша + город → персональные скоркарты». Конвейер меряет,
насколько легко клиенту достучаться до компании онлайн: как быстро и по существу отвечают на
заявку в мессенджере, как выглядят карточки на картах, сайт, профильные агрегаторы,
упоминают ли компанию ИИ-ассистенты. Итог — индекс /100, бенчмарки города (медианы и квартили)
и одна страница на компанию: что увидел клиент, место среди конкурентов, два наблюдения
(одно обязательно положительное) и одна бесплатная рекомендация.

Конвейер проверен на реальном замере: стоматологии Омска, июль 2026 — 306 точек 2ГИС,
229 брендов, волна из 148 заявок.

| Фаза | Что происходит | Справочник |
|---|---|---|
| 0 | вводные: ниша, город, сегмент вне зачёта, правила и этика | `SKILL.md` |
| 1–2 | разведка источников (сначала API, потом браузер), сбор базы, склейка точек в бренды | `references/01-разведка-и-база.md` |
| 3 | методика v1.0: пять блоков, шкалы, фиксация весов до замера | `references/02-методика-шаблон.md` |
| 4 | пассивный сбор: сайты, карты, соцсети, агрегаторы, ИИ-видимость, спот-чек | `references/04-пассивные-слои.md`, `references/06-делегирование.md` |
| 5 | волна заявок: уникальные тексты, консоль фиксации, три исхода отправки | `references/03-волна-замер.md` |
| 6–7 | расчёт индекса и бенчмарков, удалённая выдача скоркарт | `references/02-…`, `references/05-выдача-удалённая.md` |

Что заложено в правила:

- **н.д. ≠ 0.** Проверенное отсутствие даёт ноль, непроверенное выпадает из знаменателя.
  У каждой цифры есть пометка «проверено X из Y баллов».
- **Веса фиксируются до замера** и не меняются задним числом. Иначе это подгонка, а не измерение.
- **Спот-чек** скриптовых цифр против того, что видит живой посетитель. Так нашёлся фильтр
  видимости отзывов, без которого цифры расходились с карточкой.
- **Делегирование:** API-скрипты пишет основная сессия, браузерный сбор уходит дешёвым
  субагентам с жёстким форматом результата.

### Этика замера

Замер идёт под видом обычного клиента (mystery shopping), поэтому правила жёсткие:

- каждая компания получает один настоящий вопрос о реальной услуге: без фиктивных записей, броней и давления;
- все сообщения пишет и отправляет человек, агент только готовит тексты и консоль;
- публикуются только анонимные агрегаты по городу, компании публично не называются и не позорятся;
  персональная страница уходит только самой компании, бесплатно;
- про метод и про использование ИИ говорим открыто: в подписи скоркарты и в ответ на прямой вопрос;
- только открытые данные и официальные API в рамках условий площадок. Капчи, блокировки и лимиты не обходим.

Полный текст — раздел «Этика замера» в [`rating-index-ru/SKILL.md`](rating-index-ru/SKILL.md).

### Измеренный эффект

Проверка в формате skill-creator: два задания на планирование замера (агентства недвижимости,
автосервисы), 18 проверяемых пунктов, ответы агента со скиллом и без него.

| | Со скиллом | Без скилла |
|---|---|---|
| Доля выполненных пунктов | **100 %** (18 из 18) | **16 %** (3 из 18) |
| Время на задание | ≈ 670 с | ≈ 396 с |
| Токены на задание | ≈ 126 тыс. | ≈ 63 тыс. |

Без скилла агент пишет разумный, но общий план. В нём нет правила «н.д. ≠ 0», фиксации весов
до замера, отдельного аккаунта для выдачи и склейки филиалов в бренды. Цена скилла — примерно
вдвое больше токенов и времени. Выборка маленькая (по одному прогону на задание), подробности
и оговорки — в [`rating-index-ru/evals/benchmark.md`](rating-index-ru/evals/benchmark.md).
Там же лежат задания (`evals.json`) и 20 запросов для проверки срабатывания (`trigger-eval.json`).

### Ограничения

- Эталонная реализация конвейера (Python- и Node-скрипты, данные прошлого замера) в репозиторий
  не входит: в ней базы реальных компаний. Скилл ссылается на неё плейсхолдером
  `<путь к эталонной реализации>`. Если кода нет, таблица инструментов в `SKILL.md` служит
  спецификацией того, что нужно написать.
- Скилл написан по-русски и заточен под российский локальный рынок: 2ГИС, Яндекс.Карты,
  ВКонтакте, Telegram, WhatsApp, MAX.

## English summary

A collection of [Claude Code](https://github.com/anthropics/claude-code) skills.
A skill is a folder with a `SKILL.md` file (YAML front matter with a name and a "when to use"
description, plus instructions) and optional reference files that the agent loads on demand.
Install a skill by copying its folder into `~/.claude/skills/`.

**rating-index-ru** guides the agent through a "digital accessibility index" for local
businesses in a Russian city. It measures how easy it is for a client to reach a company online:
response speed and quality in messengers (one mystery-shopping inquiry per company), map
listings, website, niche aggregators and AI-assistant visibility. The output is a 0–100 index,
city benchmarks and a free one-page scorecard for every company. Ethics are built in: all
messages are sent by a human, only anonymous aggregates are published, AI use is disclosed,
and platform limits and captchas are never bypassed. In a small skill-creator benchmark
(2 planning tasks, 18 checks) the agent passed 100 % of checks with the skill versus 16 %
without it, at about twice the tokens and time. The skill is written in Russian.
